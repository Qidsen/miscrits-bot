# Miscrits Bot — план реализации

Спек: `docs/superpowers/specs/2026-10-04-miscrits-bot-design.md`. Бот живёт в том же репозитории, что и HUD,
и запускается одной программой (`Miscrits.exe`): главное окно бота + оверлей HUD + трей.

## Решения, принятые при объединении

- Пакет бота: `mbot/`. HUD остаётся в `miscrits_hud/`, общий код берётся оттуда (`catalog`, `rank`,
  `game_api`, `log_watcher`, `hotkeys`), без копирования.
- Коллекция для бота = последний `Player` из `Controller` HUD (он сам обновляет её, пока жив токен)
  + поимки бота, сделанные после этого ответа (`mbot/collection.py`).
- Горячие клавиши бота: F4 — снять элемент/шаг, F6 — пауза, F7 — стоп. F8/F9/Ctrl+F8 остаются за HUD.
- Как выглядит бой на экране пользователя, заранее неизвестно, поэтому все элементы UI — «обучаемые»:
  пользователь показывает их в игре (F4), бот хранит шаблон (картинку) или область (для OCR).

## Задачи

1. **`mbot/elements.py`** — реестр обучаемых элементов (id, подпись, вид: `button`/`region`, обязательный ли)
   и хранилище `ElementStore` (PNG + JSON с координатами в `%APPDATA%\miscrits-bot\elements\`). Тесты.
2. **`mbot/routes.py`** — маршруты (список шагов-шаблонов), запись/сохранение/загрузка. Тесты формата.
3. **`mbot/collection.py`** — лучший ранг по виду (с учётом эволюций), добавление поимок. Тесты.
4. **`mbot/brain/capture.py`** — решение kill/capture/plat по правилам спека. Тесты на все ветки таблицы.
5. **`mbot/brain/combat.py`** — модель урона (ap × times × коэффициент), самообучение (`learn.json`),
   выбор действия для «убить» и «поймать». Тесты.
6. **`mbot/screen.py`** — mss-захват, `find(template)`, OCR областей (числа, проценты, ранг, имена),
   нечёткое сопоставление имён. Тесты на синтетических картинках.
7. **`mbot/mouse.py`** — движение по кривой Безье, случайная точка внутри прямоугольника, failsafe.
8. **`mbot/bot.py`** — конечный автомат в отдельном потоке: Hunt → Battle → AfterBattle → Train → Heal,
   пауза/стоп, перерывы, события для GUI. Тесты на фейковом экране/мыши.
9. **`mbot/gui.py`** — главное окно (вкладки Бот / Обучение / Маршруты / Настройки / Журнал),
   регистрация F4/F6/F7.
10. **`miscrits_hud/app.py`** — вынести сборку HUD в функцию, общий `main` в `mbot/main.py`,
    `run_app.py` + `build.ps1` → `Miscrits.exe`.
11. README: обучение, запуск, горячие клавиши.
