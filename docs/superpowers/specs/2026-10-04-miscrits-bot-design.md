# Miscrits Bot — дизайн

Дата: 2026-10-04

## Цель

Бот для Miscrits: World of Creatures (Steam, Windows, Godot 4.6), который сам фармит опыт на одной
локации, ловит нужных мискритов и тренирует команду. Запускается как обычная программа (`MiscritsBot.exe`)
с окном: старт/пауза/стоп, настройки, обучение маршрутов, журнал и статистика.

**Вне рамок v1:** переходы между локациями (кроме фиксированного маршрута к лечилке), Telegram,
оверлей поверх игры, арена, разведение, протокольный (безмышиный) режим.

## Режим работы

Пользователь стоит в нужной локации. Бот по кругу обходит записанные точки поиска (у каждой точки
после использования кулдаун; сообщение «Come back later!» = точка на кулдауне, переходим к следующей).
Найденный бой бот ведёт до конца, затем:

1. если есть криты, готовые к тренировке, — обычная **Train** (никогда платиновая) и закрытие попапов
   (эволюция, новые способности, rank up);
2. если HP команды ниже порога — маршрут в город: **Return Home** → здание Healing → **Miscrit Healer**
   → первая опция диалога → **Okay** → выход по красной стрелке → записанный маршрут обратно на локацию;
3. следующая точка поиска.

## Правила поимки

Факты о противнике: вид (OCR имени → каталог), ранг (с экрана), HP, шанс поимки.

| Ситуация | Решение |
|---|---|
| Вида нет в коллекции (любая форма эволюции) | ловить, любой ранг |
| Вид есть, ранг противника выше лучшего имеющегося | ловить |
| Вид есть, ранг не выше лучшего | убить |
| Ранг не распознан | считать вид «нужным» только если его нет в коллекции; иначе убить |

Платиновая поимка разрешена только для редкости **Exotic** и **Legendary**, не более
`plat_capture_limit` (по умолчанию 3) попыток за бой. Для остальных — только обычная Capture.

Коллекция берётся через `get_player` при старте; после успешной поимки бот сам дописывает
(вид, ранг) в локальную коллекцию, повторно API не дёргает (токен живёт 120 мин, игра обновляет его
только по 401).

## Бой

Решение принимает `brain.combat` по фактам: способности активного крита (каталог: `ap`, `accuracy`,
`element`, `type`), вид противника и его стихия, HP противника.

- **Убить:** способность типа Attack с максимальным ожидаемым уроном `ap × accuracy × множитель стихий`.
- **Поймать:** если шанс поимки ≥ `capture_min_chance` или минимальная атака может добить —
  Capture; иначе самая слабая атака, оценочный урон которой меньше текущего HP с запасом.
- **Самообучение:** после хода бот читает фактическую потерю HP противника и хранит среднее
  «урон за единицу ap» по паре (стихия атаки, стихия цели) в `learn.json`; оценка урона = ap × этот
  коэффициент (до первых наблюдений — эвристика по уровню).
- Множители стихий: преимущество ×1.5, слабость ×0.5, иначе ×1 (уточняются самообучением).

## Минимизация риска

- Только скриншоты и клики мышью; никакого чтения памяти и вмешательства в трафик.
- `get_player` — один раз на старте, с User-Agent клиента игры.
- Клики в случайную точку внутри найденного шаблона, движение мыши по кривой, случайные задержки
  (`delay_min..delay_max`), ожидание появления кнопки вместо кликов вслепую.
- Перерывы: каждые `break_every` (30–60 мин) пауза `break_len` (2–10 мин); лимит сессии.
- Непонятный экран → скриншот в журнал и пауза, а не случайные клики.

## Архитектура

Python 3.13, PySide6 (GUI), mss (скриншоты), OpenCV (шаблоны), Tesseract (OCR), PyInstaller (exe).

| Модуль | Ответственность |
|---|---|
| `mbot/game/catalog.py` | `miscrits.json` → виды, редкость, стихии, способности |
| `mbot/game/api.py`, `token.py` | токен из `godot.log`, `get_player` → коллекция и команда |
| `mbot/game/rank.py` | ранги и их порядок |
| `mbot/brain/capture.py` | `decide(enemy, collection) -> Decision(kill / capture / plat)` — чистая функция |
| `mbot/brain/combat.py` | выбор действия в бою, модель урона, самообучение — чистые функции + JSON |
| `mbot/screen.py` | захват экрана, поиск шаблона, OCR областей |
| `mbot/mouse.py` | человеческое движение и клик |
| `mbot/templates.py` | хранилище шаблонов UI (снимаются с экрана пользователя) |
| `mbot/routes.py` | запись (горячая клавиша F4 = шаг) и воспроизведение маршрутов |
| `mbot/vision.py` | распознавание состояния экрана и чтение фактов боя |
| `mbot/bot.py` | конечный автомат Hunt → Battle → Train → Heal, поток бота |
| `mbot/control.py` | F6 пауза, F7 стоп, failsafe (мышь в левый верхний угол) |
| `mbot/gui/` | окно приложения: вкладки «Бот», «Обучение», «Настройки», «Журнал» |

`brain/*` не знает про экран и мышь, поэтому тестируется без игры.

Данные программы: `%APPDATA%\miscrits-bot\` — `config.json`, `templates\`, `routes\`, `learn.json`,
`collection.json`, `logs\`.

## GUI

- **Бот:** Старт / Пауза / Стоп, текущее состояние, статистика сессии (бои, поимки по редкости,
  тренировки, походы к хилу), последние события.
- **Обучение:** мастер, который по очереди просит навести мышь на элемент игры и нажать F4
  (точки поиска, кнопки боя, Return Home, путь к хилу и обратно). Показывает снятые шаблоны,
  позволяет переснять.
- **Настройки:** задержки, перерывы, порог HP, лимит плат-попыток, мин. шанс поимки.
- **Журнал:** живой лог.

Горячие клавиши F8/F9 заняты Miscrits HUD, поэтому у бота F4 (шаг обучения), F6, F7.

## Ошибки

- Шаблон не найден за `timeout` → повтор с проверкой состояния; три неудачи подряд → скриншот и пауза.
- Нет токена/API недоступен → бот работает с коллекцией из `collection.json`, в GUI предупреждение.
- Tesseract не найден → понятная ошибка в GUI при старте.

## Тестирование

pytest для `brain`, `catalog`, `rank`, `api`, `routes` (формат), `vision` на сохранённых скриншотах.
Ручная проверка цикла в игре.
