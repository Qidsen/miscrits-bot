# Miscrits HUD

Оверлей поверх Miscrits: World of Creatures. Сам определяет текущую зону и показывает всех её мискритов: у пойманных — ранги всех копий (от лучшего), у остальных — «не пойман».

## Запуск

Скачайте `MiscritsHUD.exe` со страницы [Releases](https://github.com/Qidsen/miscrits-hud/releases/latest) и запустите (игру можно запускать до или после). Установка и Python не нужны.

Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

Сборка exe из исходников:

    python -m venv .venv
    .venv\Scripts\python -m pip install -e .[dev]
    powershell -File build.ps1

Запуск без сборки: `.venv\Scripts\python -m miscrits_hud`. Тесты: `.venv\Scripts\python -m pytest`.

## Сегодня и другие дни

Сверху — кто водится в зоне **сегодня** (с рангами твоих копий или «не пойман»), счётчик в заголовке — по ним. Ниже, в блоке «В другие дни», — мискриты, которые появляются в этой зоне только по определённым дням, с днями появления (`пн · ср · сб`). День меняется в 00:00 UTC, как в игре (в Украине летом в 03:00, зимой в 02:00).

## Где видна панель

- Пока активна игра — панель над игрой.
- Переключился в другое окно (браузер, рабочий стол) — панель прячется и не мешает, трей и панель задач не перекрывает.
- Игра не запущена — панель видна как обычное окно с «Ждём игру…».
- Панель всегда остаётся в пределах экрана и не заходит на панель задач.

## Клавиши

- **F8** — показать/скрыть
- **F9** — обновить сейчас
- **Ctrl+F8** — режим перемещения (перетащить мышью, повторное нажатие — закрепить)

Иконка «M» в трее: показать/скрыть, обновить, переместить, **Выход**. Повторный запуск exe ничего не делает — HUD уже работает.

F8 и F9 перехватываются глобально: пока HUD запущен, другие программы их не получают.

## Ключ сессии и ограничения

Игра выдаёт ключ на 2 часа и продлевает его, только когда какое-то её окно (надёжнее всего — **Достижения**) получает отказ сервера. Пока ключ живой, HUD раз в 15 с сам спрашивает у сервера зону и коллекцию. Когда ключ истёк, HUD показывает последнюю сохранённую коллекцию, зону берёт из лога игры и подсказывает: открой в игре **Достижения** и проведи бой — после этого всё обновится само (бой нужен, чтобы игра дописала новый ключ в свой лог).

Лог игры пишется блоками по 4 КБ, поэтому без живого ключа смена зоны видна с задержкой.

## Как это работает

- Зона и ключ сессии — из лога игры `%APPDATA%\Godot\app_userdata\Miscrits\logs\godot.log`.
- Коллекция — запрос `get_player` к серверу игры (только чтение) при смене зоны и раз в 15 с, пока ключ живой и игра активна.
- Ранг — сумма шести бросков статов (7 = F … 18 = S+).
- Иконки — из кэша игры, иначе с публичного CDN игры.

Ключ сессии нигде не сохраняется. Лог программы: `%APPDATA%\miscrits-hud\hud.log`.


Использование неофициального API — на свой риск.

## Бот (MiscritsBot.exe)

Одна программа: окно бота + оверлей HUD + значок в трее. Готовый exe — в [Releases](https://github.com/Qidsen/miscrits-bot/releases/latest).
Собрать самому: `.\build.ps1` → `dist\MiscritsBot.exe`. Закрытие окна сворачивает программу в трей (HUD продолжает
работать); выход — через меню значка в трее.
Нужен Tesseract OCR (`winget install UB-Mannheim.TesseractOCR`).

Что делает: обходит точки поиска на текущей локации, дерётся (сам выбирает атаки и учится на фактическом уроне),
ловит виды, которых нет в коллекции, или экземпляры с рангом выше вашего лучшего. Платиновая поимка — только для
Exotic/Legendary и не больше N попыток за бой. Обычная тренировка, лечение у Miscrit Healer в городе.

Первый запуск — обучение (всё снимается с вашего экрана, поэтому работает при любом разрешении):
1. **Обучение**: выберите элемент → «Снять» → в игре F4 на кнопке (или F4 в двух углах области с текстом).
   Элементы боя удобно снимать во время обычного боя. «Проверить экран через 3 с» показывает, что бот видит.
2. **Точки и маршруты**: «Добавить точки» → F4 на каждой точке поиска локации.
   Маршруты «Лечение» и «Тренировка»: «Записать» → F4 на каждом шаге (бот запоминает и сам нажимает).
3. **Бот** → Старт, затем переключитесь в игру. Бот работает, только когда окно игры активно.

Горячие клавиши: **F4** — снять элемент/шаг, **F5** — старт, **F6** — пауза, **F7** — стоп; аварийный стоп — мышь в левый
верхний угол. F8/F9/Ctrl+F8 — HUD, как раньше. Данные бота: `%APPDATA%\miscrits-bot\` (обучение, настройки,
журнал, `learn.json` с выученным уроном, скриншоты непонятных экранов в `logs\`).
